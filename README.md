# City Bakery Sulur

Marketing site for City Bakery Sweet & Snacks, Sulur. React 19 + Vite, with the
React Compiler enabled.

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
npm run preview  # serve the production build
```

## Project layout

```
src/
  data/site.js            all copy, contact details and image imports
  hooks/useCarousel.js    shared slideshow state (auto-advance + manual control)
  components/
    Home.jsx              page composition
    Navbar.jsx            sticky header, mobile panel
    Hero.jsx              split hero with photo slideshow
    MenuSection.jsx       category picker + menu board
    BestSellers.jsx       product card grid
    About.jsx             story + poster carousel
    Footer.jsx            contact, address, hours
    ScrollToTop.jsx       back-to-top button
    SectionHeading.jsx    shared section header
  index.css               design tokens, reset, base typography
  App.css                 component styles
```

Text and images live in `src/data/site.js` - edit there rather than inside a
component.

## Responsive behaviour

Layout is fluid by default: fluid type via `clamp()`, and grids built with
`repeat(auto-fit, minmax(...))` so columns reflow without a breakpoint. Only
three structural breakpoints exist:

| Width      | What changes                                                |
| ---------- | ----------------------------------------------------------- |
| `< 900px`  | Hamburger menu; hero, about and footer stack to one column   |
| `>= 900px` | Full nav bar and phone button; hero and about become 2-up    |
| `>= 1200px`| Wider hero photo, roomier column ratios                      |

Every image sits in a frame with a fixed `aspect-ratio` and an explicit
`object-fit`, so switching menu category or slide never shifts the layout, and
no photo is ever stretched.

## Images

Source artwork lives in `src/assets/`. The app imports only the web-sized
derivatives in `src/assets/optimized/`, generated by:

```bash
npm run optimize:images
```

That trims the transparent padding around the logo and resizes each photo to
the largest size it is actually displayed at, taking the shipped image payload
from ~8.7 MB to ~1.5 MB. After replacing an original in `src/assets/`, re-run
the script.

## Static preview

`scripts/build-preview.ps1` renders a single self-contained HTML file
(`preview/city-bakery-preview.html`) that inlines the real stylesheets and
embeds every image, for checking layout on a device without a Node toolchain.

## Deploying

`npm run deploy` publishes `dist/` to GitHub Pages. If the site is served from a
repository subpath rather than a domain root, also set `base` in
`vite.config.js` and a matching `basename` on `<BrowserRouter>`.
